# الربط التلقائي بالأرشيف الذكي

- التاريخ: 2026-10-25
- قاعدة البيانات: `epfppicdvkklzryworzu.supabase.co` (الإنتاج)
- الحالة: **مطبَّق ومُتحقَّق منه**

## الهدف

ربط أسماء أصحاب المطالبات والقضايا والإجازات الدراسية بأعضاء هيئة التدريس
في «الأرشيف الذكي» تلقائيًا، مع دعم الأسماء المتشابهة، ورفض الربط عند
وجود غموض بدل التخمين.

## آلية المطابقة

`src/utils/facultyNameMatcher.js` + `src/utils/facultyAutoLinkPlan.js`:

1. **تطبيع الاسم**: الحروف التقديمية (NFKC)، التشكيل والتطويل، الهمزات
   (أ/إ/آ ← ا)، الألف المقصورة (ى ← ي)، التاء المربوطة (ة ← ه)، والمسافات.
2. **حذف الألقاب من البداية فقط** (د. / أ.د / الدكتور / الأستاذ / المهندس…).
   لا تُحذف «السيد/السيدة» لأنهما اسمان شخصيان شائعان.
3. **درجات الثقة**:
   - تطابق تام بعد التطبيع → `normalized_name` (1.00)
   - اسم بديل مسجّل → `alias` (0.97)
   - اختصار بادئي (نقص لقب أخير) → `partial_name` (0.88–0.94)
   - تشابه ≥ 95% مع تطابق الاسم الأول واللقب الأخير → `similar_name` (0.95)
   - اختلاف «ال» التعريف وحدها → `similar_name` (0.95)
4. **الحماية من الأخطاء**:
   - تكرار الاسم في السجل المركزي = غموض دائم (لا ربط).
   - إذا تقارب مرشحان (فرق < 0.04) لا يتم الربط.
   - التشابه الأقل من الحد يُعرض كـ«يحتاج مراجعة» مع أفضل 5 مرشحين.
5. **القضايا**: مطابقة عنوان القضية، ثم البحث عن اسم كامل (3 كلمات أو أكثر)
   داخل العنوان/الوصف.
6. **الإجازات الدراسية**: رقم الصرف أولًا (`exact_code`) ثم الاسم.
7. **عدم المساس بالروابط القائمة**: تُضاف الروابط الجديدة فقط
   (`ON CONFLICT DO NOTHING`)، ولا تُحذف أو تُعدَّل أي روابط سابقة.

## أين يعمل تلقائيًا؟

- بعد استيراد شيت المطالبات من Excel (`executeClaimsImport`).
- بعد إضافة مطالبة يدوية.
- بعد استيراد/حفظ الإجازات الدراسية.
- بعد استيراد قضايا Excel أو رفع قضية PDF.
- يدويًا: زر **«🔗 ربط تلقائي»** في صفحة الأرشيف الذكي، مع قائمة مراجعة
  وإمكانية اختيار العضو الصحيح بضغطة واحدة.

## سكربت CLI

```bash
node scripts/faculty-archive/auto-link.mjs            # معاينة فقط
node scripts/faculty-archive/auto-link.mjs --apply    # حفظ الروابط
node scripts/faculty-archive/auto-link.mjs --leaves study-leaves.json
```

- ينشئ نسخة احتياطية تلقائية من `faculty_member_links` قبل الحفظ.
- لا يكتب إلا الروابط الجديدة.
